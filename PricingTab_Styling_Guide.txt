## NOTES

1. **Tailwind Configuration**: Make sure your target project has Tailwind CSS configured with the custom colors (primary, secondary, accent, primary-dark, primary-light, primary-medium) defined in your `tailwind.config.js`.

2. **Consistency**: These styles maintain consistent spacing (using Tailwind's spacing scale), consistent border styling, and consistent interaction states.

3. **Accessibility**: Many inputs include `focus:ring-2` for keyboard navigation visibility and proper semantic HTML.

4. **Responsive Design**: The modal uses `mx-4` for horizontal margins on small screens and `max-w-md` for larger screens.

5. **Color Semantics**: Colors follow standard conventions:
   - Red: Errors, deletions, critical warnings
   - Yellow: Warnings, uninteracted items
   - Green: Success, approval
   - Blue: Info, Cost Plus feature-specific items
   - Gray: Neutral, read-only, disabled

---

## TAILWIND CONFIG REQUIREMENTS

Add these custom colors to your `tailwind.config.js`:

```javascript
module.exports = {
  theme: {
    extend: {
      colors: {
        primary: {
          DEFAULT: '#your-primary-color',
          dark: '#your-primary-dark-color',
          light: '#your-primary-light-color',
          medium: '#your-primary-medium-color',
        },
        secondary: {
          DEFAULT: '#your-secondary-color',
        },
        accent: {
          DEFAULT: '#your-accent-color',
        },
      },
    },
  },
}
```
